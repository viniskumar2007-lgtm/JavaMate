# ☕ JavaMate

JavaMate is an AI-powered Java Programming Assistant chatbot built using
Python, Streamlit, and Google Gemini.

## 📌 About the Project

JavaMate helps students learn Java programming in a simple and easy way.

The chatbot uses a Java knowledge base stored in `java.txt` and Gemini AI
to answer questions related to Java.

## ✨ Features

- Java concept explanations
- Java syntax
- Java code examples
- Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction
- Interfaces
- Exception Handling
- Threads
- Chat history
- Clear chat option

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI
- Java knowledge base (`java.txt`)
